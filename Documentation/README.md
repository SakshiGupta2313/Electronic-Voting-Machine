## Project Details

### Objective
The objective of this project is to design a simple electronic voting system that records votes using push buttons and displays the results on an LCD.

### Hardware
- Arduino
- 16x2 LCD with I2C
- 6 Push Buttons
- LED
- Buzzer
- SD Card Module

### Software
- Arduino IDE
- Embedded C/C++

### Working
The voter selects a candidate using the corresponding push button. The Arduino registers the vote, gives LED and buzzer feedback, and displays the recorded vote on the LCD. The result button displays the vote count.

### Pin Connections
- Voting Buttons: D2-D7
- Buzzer: D8
- Result Button: D9
- LED: D11
- SD Card CS: D10
- LCD SDA: A4
- LCD SCL: A5

### Project Type
ECE Mini Project
